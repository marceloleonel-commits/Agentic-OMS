## MMR

**Title:** Delivery Promise — Filter by Shipping Method in the Header (Sitewide)

**Description:** With this release, shoppers will be able to set their preferred delivery method — Shipping or Pickup — directly from the storefront header. This selection persists sitewide across PLPs and search results for the duration of the session, so every product listing reflects the shopper's chosen method without requiring re-selection on each page.

**Availability:** Open Beta · H2 2025

**Target Audience:**
- Tier: All tiers using Intelligent Search and Delivery Promise
- Persona: Shopper / E-commerce Manager
- Pain: Shoppers who always intend to pick up (or always want home delivery) must re-apply the delivery method filter on every PLP they visit. There is no persistent, sitewide way to express this preference.
- Use Case: Set delivery method preference once in the header and have it apply to all PLPs and search results throughout the session

---

## Scope

**In scope:**
- Delivery method selector (Shipping or Pickup) in the storefront header
- Selection persists sitewide across all PLPs and search results for the current session
- Consistent with the per-PLP Shipping Method filter (same radio button behavior); the header selection pre-sets the PLP filter when the shopper arrives on a PLP

**Not in scope:** Pickup point selection in the header (separate MMR), cross-session persistence (separate MMR), per-PLP filter override behavior beyond pre-setting.
