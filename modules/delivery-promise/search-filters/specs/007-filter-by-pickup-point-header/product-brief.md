## MMR

**Title:** Delivery Promise — Filter by Pickup Point in the Header (Sitewide)

**Description:** With this release, shoppers will be able to select a specific pickup point directly from the storefront header. This selection persists sitewide across all PLPs and search results for the duration of the session, so every product listing is filtered to the inventory of that specific store — eliminating repeated store selection across pages and eliminating the mismatch between browsing and checkout.

**Availability:** Open Beta · H2 2025

**Target Audience:**
- Tier: All tiers
- Persona: Shopper / E-commerce Manager
- Pain: Shoppers who always collect from the same store must re-select that store on every PLP they visit. There is no sitewide, persistent way to express store preference during a session.
- Use Case: Select a specific pickup point once in the header and have all PLPs and search results filtered to that store's inventory for the session

---

## Scope

**In scope:**
- Specific pickup point selector in the storefront header (list of stores within the shopper's configured radius, ordered by distance)
- Selection persists sitewide across all PLPs and search results for the current session
- Consistent with the per-PLP "Filter by Specific Pickup Point" behavior; the header selection pre-sets the per-PLP store filter

**Not in scope:** Per-PLP specific pickup point filter (separate MMR), cross-session persistence (separate MMR), pickup point ordering by distance logic (Pickup Point Listing MMR).
