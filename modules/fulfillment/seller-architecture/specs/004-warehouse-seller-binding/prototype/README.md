## Current mock coverage

- Warehouse configuration screen with the new **"Sellers internos"** card.
- Card visibility depends on the account:
  - Non-`sellerType=3` account: the card is not shown.
  - `sellerType=3` account: searchable dropdown to select one active seller by account name.
