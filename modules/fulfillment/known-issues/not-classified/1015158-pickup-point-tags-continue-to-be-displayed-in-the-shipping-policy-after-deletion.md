# KI 1015158 — Pickup Point Tags Continue to Be Displayed in the Shipping Policy After Deletion

| Field | Value |
|---|---|
| **Area** | Logistics |
| **Status** | Backlog |

**Description:** Tags registered at a pickup point are available in a dropdown within shipping policies, used to link the pickup point (PUP) to the shipping policy. However, when any of these tags are deleted from the PUP, they remain available in the dropdown within the shipping policy, leading to stale data.

**Workaround:** There is no workaround available.
