# KI 775800 — Modal Values with Different Texts Between API and Logistics UI

| Field | Value |
|---|---|
| **Area** | Logistics |
| **Status** | Backlog |

**Description:** In the General Settings screen of the logistics module, when configuring available modal values for the catalog, the selected values are not translated in the API. As a result, the values displayed in the catalog UI may not match the values shown in the logistics UI, because the catalog UI uses the raw API value. This causes a mismatch when a non-EN language is used.

**Workaround:** When enabling each modal value in logistics, validate its equivalence with the Catalog UI to ensure the text matches.
