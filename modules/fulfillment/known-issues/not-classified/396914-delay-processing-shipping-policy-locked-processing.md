# KI 396914 — Delay in processing shipping policy locked in processing

| Field | Value |
|---|---|
| **Area** | Logistics / Shipping |
| **Status** | Backlog |

**Description:** Shipping policies can get stuck in a "processing" state for extended periods, causing delays in order processing. When this happens, the shipping policy is locked and unavailable for use in simulations or checkout until the processing completes or times out.

**Workaround:** Wait for the processing to complete naturally. If the issue persists for an extended period, contact VTEX support to manually unlock the shipping policy.
