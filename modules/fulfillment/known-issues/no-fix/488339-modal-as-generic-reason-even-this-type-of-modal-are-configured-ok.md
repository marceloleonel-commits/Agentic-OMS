# KI 488339 — Modal as Generic Reason Even This Type of Modal Are Configured OK

| Field | Value |
|---|---|
| **Area** | Logistics |
| **Status** | No Fix |

**Description:** There is a scenario where modals are configured correctly in both the SKU and the Shipping Policy, but the simulation still shows an error with a generic modal reason. The shipping policy appears correctly set up on the UI, but checking the API reveals a mismatch in the modal configuration.

**Workaround:** There is no workaround for this case.
