# KI 488362 — Simulation Is Not Possible to Find Products from Catalog V2 on Shipping Simulation Page

| Field | Value |
|---|---|
| **Area** | Logistics |
| **Status** | No Fix |

**Description:** On accounts using Catalog V2, the autocomplete search on the Shipping Simulation page does not find products. The loading icon does not finish and no results are returned, making it impossible to simulate shipping for products from Catalog V2.

**Workaround:** There is no workaround for this case.
